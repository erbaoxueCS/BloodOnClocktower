# 小红书 Staycation 酒店测评文案

用本 skill 写/改 staycation 系列酒店笔记。输出必须可直接粘贴发布；默认简体中文。

## 何时使用

- 写新一篇 staycation 酒店测评
- 优化用户草稿，使结构与语气对齐系列模版
- 只改某一段落（房间、餐食等）时，改完后按需嵌回全文

## 固定结构（按此顺序，不要擅自增减一级标题）

```
✨【一句话总评】
🏛️【酒店公区】
🛏️【房间&设施】
🍽️【餐食情况】
📍【周边环境】
💡【总结&适合人群】
#话题标签…
```

说明：
- **不要**默认加「出片程度」「入住小Tips」等额外一级板块，除非用户明确要求。
- 一级标题用 emoji + 【】；条目用 `▫️`；适合/不适合用 `✅` / `❌`。

## 各段写法

### ✨【一句话总评】
- 两句为主：①地点+酒店名+核心体感/亮点钩子；②「不用跑远 / 城市微度假」价值 + 适合谁。
- 可加一句个人动机（如冲设计、冲湖景），但不要写成广告口号。

### 🏛️【酒店公区】
- 大堂位置与氛围（人流、香调、设计观感——可坦白「不 get」）。
- 配套清单：健身房、泳池、桑拿、餐厅等，只写有体验或确认过的。
- 可做横向对比（其他同品牌/同级酒店），保持个人口吻。

### 🛏️【房间&设施】
固定四条（有则写，无则省略该条，不要编造）：
1. **房型**：如何拿到（正价/升舱/积分）、面积、视野、通透感
2. **内部配置**：分区、床品、卫浴、迷你吧、WiFi、充电、隔音等
3. **细节亮点**：自拍机位、灯光、选房建议（如高楼层）
4. **减分项**：异味、布局槽点、投屏/电视等真实差评——必须保留诚实度

### 🍽️【餐食情况】
固定可含：
1. **早餐**：楼层、时段、口味总评（可用「无功无过」）、档口要点
2. **嘉宾轩/行政酒廊**（若有）：下午茶、HH 等，写清强推点；可用「（图N）」指图
3. **其他**：正餐、大堂吧、主题自助；预约/靠窗提示
4. **缺点**：人流、排队、划水等真实体验

### 📍【周边环境】
1. **位置**：商圈、自驾/停车/充电、地铁+打车时长
2. **附近**：步行可达点；可吐槽「楼下商场没啥」
3. **玩法**：纯躺 / 散步 / 看展看剧等；有优惠、具体场次可写进体验

### 💡【总结&适合人群】
- `✅适合：` 逗号并列人群标签
- `❌不太适合：` 明确劝退谁
- 与总评人设一致，不要矛盾

### 话题标签
- 文末一行，空格分隔，形如 `#上海staycation #酒店名简称 #上海酒店测评 #城市微度假 #周末去哪儿 #江浙沪`
- 可按城市/酒店替换，一般 5–8 个；不要写「[话题]」字样

## 语气与风格硬规则

1. **真人测评感**：口语、短句、可连刷；允许「很香 / chill / 人挤人 / 划水 / 不 get」。
2. **褒贬都要有**：至少保留可感知的减分点；禁止通篇安利。
3. **具体 > 空泛**：楼层、时段、面积、会员身份、升舱方式、距离、价格优惠等能写则写。
4. **不编造**：用户没给的设施、价格、评分不要补；缺信息就留空或只改已有段。
5. **系列统一**：新稿对齐本模版分区与符号；用户改过定稿后，以用户最新全文为准再微调措辞，不回退结构。
6. **输出形态**：默认直接给完整可发文案；用户只要某一段时只给该段，并问是否嵌回全文（若上下文已在迭代全文，则直接嵌回）。

## 工作流

1. 读用户素材/草稿，标出已有事实与缺口。
2. 按六段模版重组；保留用户原话里的主观判断与槽点。
3. 对照 `references/example-jiading-hyatt.md` 校对密度与口气。
4. 输出终稿；若只改一段，嵌回完整篇再交。

## 反例（避免）

- 写成小红书「种草文案机器味」：全是「绝绝子」「闭眼入」无细节
- 把公区/房间/餐食揉成一大段
- 删除用户明确写过的缺点来「更好看」
- 擅自加回已去掉的「出片程度」「入住小Tips」板块
